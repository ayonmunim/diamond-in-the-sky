# Mission 4: Star Colors

Only Mission 4 uses this new presentation. Other missions retain their existing stories and activities.

## Activities

1. Discover five star-color families, including intermediate shades. Hover or focus for colored names; tap stars to collect them. Distractors give gentle feedback.
2. Sort five named stars into Hot, Warm, and Cool. Drag, or select a star and tap its destination.
3. Drag stars onto a horizontal temperature scale. Incorrect matches return to the tray. Keyboard users can select a star and then its destination.
4. Type Red, Orange, Yellow, White, Blue into five circles, coolest to hottest. Correct spelling transforms each circle.
5. Aim at True or False and launch an arrow to test five star facts. Incorrect shots can be retried.

Each level includes an original live 2D cartoon introduction with Nova, scene controls, optional browser narration, and a Nova medal celebration. These are browser-rendered animations, not new exported MP4 files. Narration availability and voice depend on the device and game sound settings.

## Learning examples

| Color | Temperature | Example |
| --- | --- | --- |
| Blue | 25,000 K | Spica |
| White | 10,000 K | Vega |
| Yellow | 6,000 K | Sun |
| Orange | 4,000 K | Aldebaran |
| Red | 3,000 K | Betelgeuse |

These are the requested rounded educational examples, not precise measurements for every named star. All stars are hot; cool is relative. The Sun appears white from space. Temperature markers are evenly spaced for interaction rather than plotted on a linear numerical axis.

## Undo this phase

From this project folder in PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\UNDO-STAR-COLORS-PHASE.ps1
```

This restores the pre-change route from `.review-backup/star-colors-v9`, saving the current route in a separate safety folder first. New component/data/style files remain unused. It does not reset saved player progress or delete media. Use this before making later edits to the same route; restoring replaces the entire route file.
