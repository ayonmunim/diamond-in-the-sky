# Mission 1: connected thinking activities

This phase changes only the five existing C1 / M1 star-learning activities. It retains their space artwork, Nova, story videos, star-creation concepts and reward flow. Other missions and Explore Universe are unchanged.

- L1: follow a numbered cloud trail before gravity brings the cloud together.
- L2: complete a hydrogen/helium pattern, then compress the cloud.
- L3: study numbered/color-coded hydrogen signals, optionally hide them, and recall the sequence. Show the signals again at any time.
- L4: guide each numbered energy spark through three beacons towards the surface.
- L5: combine the cloud trail, gravity, fusion and light route.

The patterns and beacons practise sequencing, matching, memory and planning. They are navigation challenges, not new laws of physics, exact gas proportions or claims of clinically proven brain improvement. Learning notes explicitly explain the simplified model.

Mouse/touch: drag an object to its glowing target, or select it and tap the target. Keyboard: Tab to an object and press Enter or Space to move it to the current target. Incorrect choices provide a hint without losing progress. Restart resets the current activity, including memory visibility and beacon progress.

```powershell
cd D:\Munim\diamondinthesky
powershell -ExecutionPolicy Bypass -File .\UNDO-BRAIN-LEARNING-PHASE.ps1
```

The undo script first saves current files in a timestamp-independent unique backup folder, then restores the previous activity component and stylesheet. It does not delete player progress or media. The new helper module remains unused after undo.
